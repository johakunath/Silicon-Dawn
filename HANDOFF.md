# Handoff

## State (2026-11-19)
- The full game is playable: title → 5-era campaign → finale → sandbox unlock. `npm run dev`, then open http://localhost:5173.
- Tests: `npm test` (19 tests, including the autoplayer finishing the whole campaign on the campaign seed in about 60 sim-minutes).
- Screenshots of every era and overlay are in `screenshots/` (generated by `npx tsx scripts/shots.ts eraN`; run `npx tsx scripts/mksaves.ts` first so they load fast from `.cache/`).

## Last work in progress
- Perf pass at 677 buildings (`shots.ts stress`). Before the fix: 36 fps, caused by DOM badges. After moving badges to a canvas: median 90 fps, but **p95 was 90 ms (spikes)**. I then removed per-packet allocations (a suspected GC cause), but **this has not been re-measured yet**. Next step: run `PERFBISECT=1 npx tsx scripts/shots.ts stress`. If the spikes remain, profile the 4 Hz HUD slow update and `WorldView.refreshOverlay`.

## Known issues
- On some sandbox seeds (for example 777), the autoplayer stalls in era 4. This is a bot weakness, not a game deadlock.
- Balance is based on the bot. It needs human tuning; see `PLAYTEST.md`.
- The Claude browser pane throttles rAF while it is hidden, so use the Playwright scripts (system Edge) for screenshots and benchmarks.
